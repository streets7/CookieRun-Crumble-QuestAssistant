브라우저 제어 화면 실행
- 'CookieRunQuestAssistant.app'을 더블클릭하면 쿠키런: 크럼블 퀘스트 도우미가 실행됩니다.
- 잠시 후 기본 브라우저에 제어 화면이 자동으로 열립니다.
- 인터넷을 사용하지 않으며 주소는 이 Mac 안에서만 열리는 127.0.0.1:8765 입니다.
- 시작 메뉴에서 반복 횟수를 선택합니다. 실행 전 화면·해상도·현재 퀘스트를 자동으로 한 번 점검합니다.
- 자동 시작 점검의 퀘스트 판별이 불확실하면 최대 3회 재확인합니다. 완화된 신뢰도 기준을 사용하되 다른 퀘스트와 점수 차이가 작으면 실행하지 않습니다.
- 반복 횟수는 1~100회를 직접 입력하거나 `+10회` 버튼을 반복해서 눌러 10·20·30회처럼 누적할 수 있습니다. 최대 100회이며, ∞를 선택하면 정지 버튼을 누를 때까지 계속합니다.
- 무한 반복 중 화면 판별·전환 오류가 나면 전체 오류 횟수, 같은 오류 횟수, 연속 오류 횟수, 완료 퀘스트 수와 원인을 로그에 남기고 전투 화면부터 다시 판별합니다.
- 무한 반복 오류 시 현재 화면을 분류해 알려진 팝업을 안전하게 정리하고, 전투 화면에서 현재 퀘스트를 다시 확인한 뒤 해당 퀘스트부터 재시작합니다.
- Unknown 계열 오류가 3회 연속 발생하면 화면을 두 번 확인한 뒤 BlueStacks Air의 Android 뒤로가기를 최대 5회 사용합니다. 전투 메인 화면이 확인되는 즉시 멈추고 현재 퀘스트부터 재시작합니다.
- 무한 반복 오류 보고에는 오류 전 화면, 당시 퀘스트, 자동 복구 결과, 복구 후 화면과 직전 실행 기록을 저장합니다. 오류 보고 복사 버튼으로 전체 내용을 복사해 문제 분석에 사용할 수 있습니다.
- 실행 로그 제목 옆의 `(실행횟수:000)` 카운터는 정상 처리한 퀘스트마다 증가하며 새 실행 시 000으로 초기화됩니다.
- 크리스탈·알 수 없는 비용, 연결 도구·해상도 문제 등 안전 관련 오류는 무한 반복이어도 즉시 중단합니다.
- 세부 설정 탭에서 대기시간과 화면 좌표를 수정하고 저장할 수 있습니다.
- 시작 버튼으로 지정 횟수를 실행하고, `∞ 바로 시작` 버튼은 자동 점검 후 즉시 무한 반복을 시작합니다. 정지 버튼으로 즉시 정지를 요청합니다.
- `∞ 바로 시작` 옆의 프로그램 종료 버튼은 실행 작업에 정지 신호를 보내고 로컬 제어 서버까지 함께 종료합니다.
- 시작 시 오른쪽 퀘스트를 자동 판별하므로 특정 퀘스트 순서에 맞출 필요가 없습니다.
- 각 클릭 뒤 예상 화면과 실제 화면이 일치한 경우에만 다음 동작으로 넘어갑니다.
- 화면 확인 주기를 단축해 반응 속도를 높였으며, 최대 대기시간과 화면 검증·안전 중단 조건은 그대로 유지합니다.
- 퀘스트 보상 수령 직후 현재 퀘스트를 한 번 더 확인합니다. 랜덤으로 나타난 퀘스트가 이미 완료 상태면 보상을 연속 수령합니다.
- `몬스터 20마리 처치`와 `몬스터 처치하기 2,000/2,000` 완료 카드를 모두 몬스터 완료 퀘스트로 판별합니다.
- 펫·쿠키 뽑기에서 X를 누른 뒤 실제로 닫혔는지 다시 확인합니다. 좋은 등급 연출로 클릭이 무시되면 연출이 끝난 뒤 X를 최대 5회 재시도합니다.
- 연속 보상 수령 직후 퀘스트 패널 클릭이 무시되면, 전투 화면이 계속 보일 때만 자동 이동을 최대 5회 재시도합니다.
- 가방에서 전부 열기 후 기존 보상창과 모양이 다른 연출이 나와도 하단 X를 확인합니다. X 클릭 후 가방 또는 전투 화면이 실제로 나올 때까지 최대 5회 재시도합니다.
- 가방 상자는 수량을 줄이지 않고 기본 수량 그대로 전부 열기를 선택합니다.
- 장비 비교 창에서 장착 버튼의 노란색 점멸을 여러 화면으로 확인합니다. 노란색이면 장착, 아니면 판매합니다.
- 장착/판매 확인은 Auto 장비 15회 실행 직후 제공된 형태의 장비 비교 화면이 확인된 경우에만 실행합니다. 비교 화면이 없거나 다른 경로에서 나타나면 버튼을 누르지 않습니다.
- Auto 외부에서 장비 비교 화면으로 일시 판별되면 가챠·보상 전환 화면으로 보고 아무 버튼도 누르지 않은 채 전투 화면 전환을 기다립니다.
- Auto 결과 장비 비교창이 보상 처리 뒤 늦게 나타나는 경우를 위해 Auto 시작 후 최대 3분 동안만 지연 비교창을 처리합니다.
- 보상 수령 직후 가챠·가방·장비 비교 화면이 자동으로 열리면 보상을 다시 누르지 않고 해당 화면을 정리한 뒤 전투 화면으로 복귀합니다.
- 절전 모드, 알 수 없는 화면은 자동으로 중단합니다.
- Crumble Level Up 레벨업 화면과 하단 `화면을 탭하세요` 문구가 함께 확인되면 안내 영역을 한 번 탭하고 전투 화면으로 복귀해 퀘스트를 계속합니다.

기존 터미널 방식
- CookieRunQuestAssistant.command를 더블클릭합니다.

처음에는 반드시 1번 '점검 실행'을 선택하세요. 점검 실행은 실제 화면을 클릭하지 않습니다.

실제 실행 전 조건
1. BlueStacks Air와 쿠키런: 크럼블을 실행합니다.
2. 모든 팝업을 닫고 전투 화면으로 돌아갑니다.
3. 오른쪽에 현재 퀘스트가 표시되어 있는지 확인합니다. 순서는 자동으로 판별합니다.
4. 실행파일에서 2번 실제 실행을 선택합니다.
5. 반복 횟수를 입력하고 '시작'을 입력합니다.

긴급정지
- 실행 중인 창을 선택하고 Control+C를 누릅니다.

자동 안전 중단
- 10회 뽑기 비용이 크리스탈인 경우
- 비용을 뽑기권으로 확정할 수 없는 경우
- 예상한 하단 중앙 X가 없는 경우
- 퀘스트 완료가 제한시간 안에 확인되지 않는 경우
- BlueStacks 화면 크기를 읽지 못하는 경우

주의
- 화면 크기는 자동 변환되며 세부 설정 좌표는 1080x1920 기준으로 입력합니다.
- 웹 화면에서 시작 전 BlueStacks 크기 맞춤을 켜면 선택한 가로·세로 크기로 변경된 뒤 실행합니다.
- 실제 스크린샷 크기가 선택값과 다르면 클릭을 시작하지 않고 안전 중단합니다.
- 화면 비율에 따라 게임 UI 배치 자체가 바뀌는 경우에는 점검 모드로 먼저 확인하세요.
- 게임 업데이트로 버튼 위치나 색상이 바뀌면 사용을 중단하세요.
- 자동화 프로그램은 게임 이용약관 위반 및 계정 제재 대상이 될 수 있습니다.
